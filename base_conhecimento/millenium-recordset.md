# Erro de registro em sistema corporativo

Um sistema web pode apresentar erro quando uma consulta não encontra o registro
esperado ou quando um cadastro obrigatório está incompleto.

Antes de escalar o incidente, valide os dados informados e registre evidências.

Roteiro de verificação:
1. Confirme se todos os campos obrigatórios estão preenchidos.
2. Repita o acesso em uma janela privada para descartar cache local.
3. Registre horário, tela, ação realizada e mensagem exibida.
4. Encaminhe o chamado à equipe responsável sem anexar dados pessoais desnecessários.
